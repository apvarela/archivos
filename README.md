# Ejes temáticos: propuesta de íconos

Esta propuesta asigna un ícono más representativo para cada eje temático usando Font Awesome.

## Mapeo recomendado

- **Auditoría Interna Estratégica y Generación de Valor** → `fa-chart-line`
- **Innovación, Tecnología y Auditoría Inteligente** → `fa-microchip`
- **Riesgos Emergentes y Resiliencia Organizacional** → `fa-shield-halved`
- **Gobernanza, Ética y Confianza** → `fa-scale-balanced`
- **Talento Auditor y Futuro de la Profesión** → `fa-user-graduate`

## Ejemplo de uso

```html
<div class="three columns" style="text-align: center; padding: 10px 30px;">
  <i class="fa-solid fa-chart-line text-blue2 fa-3x" style="padding-bottom: 20px; color: #009ee3;"></i>
  <h3 class="portfolio-title text-blue2" lenguageKey="language_141">Auditoría Interna Estratégica y Generación de Valor</h3>
  <p lenguageKey="language_142">...</p>
</div>

<div class="four columns" style="text-align: center; padding: 10px 30px;">

<div class="three columns" style="text-align: center; padding: 10px 30px;">
```
